# Lumen identity

The Lumen mark is a lowercase `lm`, the unit symbol for the lumen. The lime `l` and warm-white `m` sit on a dark rounded square.

## Files

- `lumen-mark.svg`: primary compact mark for app chrome, avatars, and icons.
- `lumen-lockup-dark.svg`: horizontal logo for dark backgrounds.
- `lumen-lockup-light.svg`: horizontal logo for light backgrounds.
- `lumen-mark-mono-dark.svg`: single-ink dark-background treatment.
- `lumen-mark-mono-light.svg`: single-ink light-background treatment.

## Palette

- Lumen lime: `#c9f560`
- Cinema black: `#0d1016`
- Warm white: `#f5f7f2`
- Ink: `#121708`

## Usage

Keep clear space equal to one quarter of the mark's width. Use the compact mark no smaller than 24 px digitally; use the horizontal lockup no smaller than 120 px wide. Do not stretch, rotate, recolor, shadow, or place the mark on a visually busy background.
