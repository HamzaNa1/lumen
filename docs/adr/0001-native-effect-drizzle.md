# Native Effect Drizzle cohort

The server uses Effect `4.0.0-beta.83`, the matching Bun platform and SQLite packages, and Drizzle `1.0.0-rc.4`. Drizzle RC4 provides the verified native `effect-sqlite-bun` driver. This explicitly deviates from a literal both-packages-beta rule; the compatibility suite is the release gate for the pinned pair.
