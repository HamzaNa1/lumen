# Desktop UI redesign screenshots

Captured from the isolated demo library. The before images are from the original desktop UI; the after images cover the redesigned flows and states. Images are resized to 1920 pixels wide to keep the repository footprint manageable.

The current player and return screenshots were recaptured on the feature branch. The player image combines the current overlay capture with a matching demo video frame because the video is rendered in a separate native surface.
